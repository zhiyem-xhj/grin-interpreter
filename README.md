# Grin Interpreter

A custom programming language interpreter implemented in Python for ICS 33 at the University of California, Irvine.

## Overview

This project implements an interpreter for **Grin**, a simplified programming language inspired by BASIC. The interpreter reads Grin source code, parses statements, manages program state, and executes programs according to the language specification.

The project was developed using object-oriented design principles and includes automated unit tests to verify functionality.

## Features

* Lexical analysis and token processing
* Parsing of Grin statements
* Variable assignment and management
* Arithmetic operations

  * ADD
  * SUB
  * MULT
  * DIV
* Input and output operations

  * INNUM
  * INSTR
  * PRINT
* Control flow

  * GOTO
  * GOSUB
  * RETURN
  * END
* Conditional branching using comparison operators
* Label support
* Runtime error handling
* Unit testing with Python unittest
